# chinese-ai — прослойка между сайтом и нейросетью

Cloudflare Worker, через который сайт обращается к нейросети Qwen
(через российский агрегатор [Polza.ai](https://polza.ai)). Сайт отправляет
только название задачи и данные. Системные промпты, модели и лимиты лежат
здесь, а ключ API — только в секретах Cloudflare: его нет ни в коде сайта,
ни в git.

- Адрес: https://chinese-ai.overh3avennn.workers.dev
- Проверка: откройте адрес в браузере. Ответ `{"ok":true, … ,"ready":true}`
  значит, что всё в порядке. `"ready":false` — не задан ключ.

## Что где лежит

| Файл | Что в нём |
| --- | --- |
| `wrangler.toml` | имя воркера, модели, адрес Polza, разрешённые адреса сайта, лимит запросов |
| `src/tasks.js` | задачи: системный промпт, модель и пределы каждой |
| `src/index.js` | приём запросов: CORS, размер, ошибки, логи, запрос к Polza |
| `src/util.js` | общие мелочи: ошибки, разбор JSON из ответа нейросети |

На сайте к воркеру обращается `js/ai.js`, там же записан его адрес.

| Задача (`task`) | Где на сайте | Модель |
| --- | --- | --- |
| `chat` | ИИ-помощник (`assistant/`) | `QWEN_MODEL` |
| `explain-word` | «Объяснить» в словаре (окно слова) | `QWEN_MODEL` |
| `notebook-cards` | сайт больше не вызывает (см. ниже) | `QWEN_VISION_MODEL` |

«Карточки по фото тетради» с ноября 2026 распознают фото прямо в браузере
(`js/notebook-ocr.js`, модели — в репозитории `chinese-dictionary-data`,
папка `ocr/`) и без VPN. Задача `notebook-cards` оставлена в воркере как
запасной вариант.

## Команды

Все команды запускаются из этой папки:

```sh
cd ~/Desktop/chinese-platform/chinese-learning-platform/ai-worker

npx wrangler deploy                    # выложить изменения кода или настроек
npx wrangler secret put QWEN_API_KEY   # задать или сменить ключ Polza (вводится скрыто)
npx wrangler tail                      # смотреть логи в реальном времени (Ctrl+C — выход)
npx wrangler login                     # если wrangler попросит войти в Cloudflare
```

## Как сменить модель или провайдера

Модели и адрес API — переменные в `wrangler.toml`, раздел `[vars]`:

- `QWEN_MODEL` — модель для текста (помощник, объяснение слова);
- `QWEN_VISION_MODEL` — модель для фото (нужна модель с `image` во входах,
  см. [каталог Polza](https://polza.ai/models));
- `QWEN_BASE_URL` — адрес OpenAI-совместимого API;
- `QWEN_REASONING`, `QWEN_VISION_REASONING` — «рассуждения» модели для текста
  и для фото: `none` — выключены (быстрее и в разы дешевле), `low` / `medium` /
  `high` — включены, пусто — параметр не передаётся (для моделей без
  рассуждений).

Сейчас обе задачи на `qwen/qwen3.8-flash`, рассуждения выключены. Проверено
4 ноября 2026: ответ помощника — 9–17 с и около 3–4 копеек, объяснение слова —
5–13 с, фото тетради — около 16 с. С рассуждениями (`low`) эта модель думает
дольше лимита: ответы бывали пустыми или не успевали за минуту.

Модель должна быть разрешена ключу: в кабинете Polza у ключа есть белый
список моделей. Иначе Polza отвечает 403 «Модель … недоступна для данного
API-ключа» (видно в `npx wrangler tail`), а сайт — «ИИ временно недоступен».

Поменяйте значение и выполните `npx wrangler deploy`. Если новый провайдер —
не Polza, задайте и его ключ: `npx wrangler secret put QWEN_API_KEY`.

## Как добавить задачу

1. В `src/tasks.js` допишите в `TASKS` новую запись — образец в комментарии
   в начале файла. В ней системный промпт, модель (`text` или `vision`) и
   пределы.
2. `npx wrangler deploy`.
3. На сайте вызовите её через `AI.ask("имя-задачи", { …данные… })` из
   `js/ai.js`.

## Защита

- Запросы принимаются только с адресов из `ALLOWED_ORIGINS` (CORS + проверка
  заголовка `Origin`). Чтобы открыть локальную копию сайта, она должна быть на
  `http://localhost:8000` или `http://127.0.0.1:8000`.
- Размер запроса: до 64 КБ для текстовых задач, до 3 МБ для фото
  (`maxBodyBytes` в задаче). Фото сжимается ещё в браузере, обычно до
  300–500 КБ.
- Длина ответа ограничена `maxTokens` каждой задачи.
- Не больше 20 запросов в минуту с одного IP (`[[ratelimits]]` в `wrangler.toml`).
- Совет: в [консоли Polza](https://polza.ai/dashboard) задайте лимит расходов
  для ключа. Это самая надёжная защита баланса.

## Логи и ошибки

Каждый запрос пишет одну строку JSON: задачу, модель, время, токены и
стоимость в рублях (`costRub`). При ошибке там же код и причина, например
`not_configured` (нет ключа) или `ai_unavailable` с ответом Polza: 402 —
кончились деньги, 401 — неверный ключ. Смотреть логи:
`npx wrangler tail` или панель Cloudflare → Workers & Pages → chinese-ai → Logs.

Сайт получает короткое понятное сообщение по-русски. Подробности Polza
остаются только в логах.
